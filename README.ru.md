# Платная гибкость против ИИ-перебронирования

Синтетический кейс по ценообразованию в B2B-отелях. План пилота на 90 дней: гибкость продаётся отдельно, глубокая скидка живёт только в закрытом канале, эффект измеряется до масштабирования на весь портфель.

Все цифры смоделированы. В репозитории нет данных реальной компании.

**Открыть мемо:** [index.html](index.html) · [PDF](pilot-plan.pdf)

Переключатель языка: RU / EN в правом верхнем углу страницы.

## Что внутри

- Бизнес-проблема: бесплатная отмена дорожает, когда ИИ-агенты перебронируют при каждом снижении цены
- Предлагаемое решение: твёрдая бронь как базовая цена; премия за гибкость по горизонту заезда (4% / 8% / 11%); глубокий тариф только в закрытом канале
- Экономика на синтетическом портфеле 133,2 млн € GBV: +0,50 млн € чистой выручки в квартал как обязательство пилота, до +1,40 млн € при масштабировании, 2,10 млн € текущей выручки под защитой
- Правила пилота, критерии остановки, риски и рекомендации смежным командам

## Как открыть

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python -m http.server 8080
```

Затем откройте `http://127.0.0.1:8080/`.
